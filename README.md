# Enrico Vezzali
### Senior Machine Learning Engineer | Ph.D. Researcher

I specialize in the research, optimization, and deployment of deep neural networks on resource-constrained embedded platforms. My engineering focus is on maximizing inference efficiency at the edge through quantization, sparsity, and custom SIMD kernel development.

### 📂 Highlighted Open-Source Work
The repositories pinned below represent my research and industrial output targeting edge architectures:

*   **[VAR-Compressor](https://github.com/Henvezz95/VAR-Compressor):** An optimization framework developed at ETH Zurich for compressing and deploying Visual Autoregressive (VAR) generative models on NVIDIA Jetson Orin.
*   **[Mosaic-SR](https://github.com/Henvezz95/mosaic-sr):** Source code associated with the patent-pending super-resolution algorithm utilizing custom NEON/AVX kernels, achieving a 30% increase in industrial scanner range. 
*   **[BarBeR](https://github.com/Henvezz95/BarBeR) & [BaFaLo](https://github.com/Henvezz95/BarBeR/tree/main/BaFaLo):** Open-source CNN architectures and a comprehensive benchmarking repository optimized for Arm CPU edge platforms.
*   **[Foot DaQ](https://github.com/Henvezz95/FOOT-Data-Acquisition-System):** Low-level VHDL implementation of a Data Acquisition System for nuclear physics experiments on FPGA hardware.
